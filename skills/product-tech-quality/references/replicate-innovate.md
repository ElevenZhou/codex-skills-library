# 复刻微创新检查表

## 1. 对标准入

| 字段 | 要求 |
| --- | --- |
| 对标产品 | 名称、网址、所属公司、地域 |
| 被验证证据 | 付费用户 / 收入 / 留存 / 下载量 / 真实口碑，至少一项有来源和日期 |
| 与我方的相关性 | 同一用户群、同一场景，还是只是形态相似 |
| 证据等级 | A 一手数据 / B 可信二手 / C 推断（C 级不能作为唯一依据） |

没有被验证证据的产品，只能作为灵感，不能作为对标。

| --- | --- | --- | --- | --- |

## 3. 复刻清单

只列被验证的核心。每条写：复刻什么、为什么（证据）、我方实现方式、验收标准。

## 4. 微创新卡片（最多 3 张）

```markdown
### 微创新 N：<一句话>
- 针对的痛点：（用户原话或数据来源）
- 对标为什么没做：（成本 / 市场 / 技术 / 不知道）
- 我方做法：
- 最小验证实验：（多少用户、多长时间、看什么指标、成功线）
- 失败退回：（退回复刻原方案的方式）
- 成本：（人力、钱、时间）
```

## 5. 合规边界

- 复刻方法、流程和体验；不复制代码、文案、图片、品牌、商标、受保护数据。
- 开源依赖查许可证：GPL / AGPL 类要评估商用影响。
- 涉及数据抓取、用户数据迁移、竞品比较宣传，交老五评估。

## 6. 方案结论

用华强输出格式。结论只能是：**直接复刻** / **复刻 + 微创新** / **先做验证实验** / **不复刻**。
