# Free-First Frontend Toolkit

Use this reference to select inspiration, vocabulary, components, and motion without making paid services part of the workflow.

## Video Tools

| Tool | Default status | Best use | Guardrail |
| --- | --- | --- | --- |
| NameThatUI | Free | Identify precise UI pattern names and improve specifications | Vocabulary only; it does not replace design judgment |
| Kinetics | Free | Spring-based CSS/React interaction references and prompts | Use on a few meaningful interactions, not every element |
| CSS Text Effects | Free examples | Explore headline and text treatments | Check each snippet's author/license and preserve readability |
| 21st.dev | Free browsing only | Study component composition and implementation ideas | Do not rely on paid builder, credits, MCP, or team features |
| MotionSites | Excluded by default | Visual and motion inspiration | Premium product; use only after explicit user opt-in |

## Free Agent and Design Context Projects

Use these as references, not mandatory dependencies:

1. Existing local `frontend-design` skill for distinctive visual authorship
2. Impeccable for anti-slop rules and brand/product mode separation
3. VoltAgent `awesome-design-md` for concrete design-system context
4. Existing local `ui-ux-pro-max` for UX states and accessibility
5. Microsoft `frontend-design-review` for a critical review pass
6. Composio `theme-factory` for reusable theme-token ideas
7. Mantine skills when the project already uses Mantine

## Free Component and UI Sources

Choose based on project fit, not ranking alone:

| Source | Best fit | Notes |
| --- | --- | --- |
| Radix Primitives | Custom React design systems | Accessible, unstyled foundations |
| shadcn/ui | React/Tailwind product UI | Own the code and restyle it; never ship the default look unchanged |
| Mantine | Full product apps and dashboards | Prefer when a broad, stable component system is useful |
| Magic UI | Expressive landing-page moments | Use sparingly outside marketing or portfolio work |
| Animata | Local React/Tailwind interaction patterns | Copy only the piece that serves the concept |
| Animate UI | Animated React primitives | Good for coherent state transitions and micro-interactions |
| React Bits free components | Creative portfolios and campaigns | Confirm the selected component is in the free set |
| Ant Design | Dense enterprise tools | Strong default for Chinese enterprise workflows; customize the theme |
| MUI core | Existing Material projects | Keep when already adopted; not the first choice for distinctive new work |

## Paid or Freemium Exclusions

Do not recommend or depend on these by default:

- MotionSites premium library
- v0 paid credits
- Bolt paid tokens
- Lovable paid credits
- Framer paid publishing or AI features
- Aceternity Pro
- React Bits Pro
- 21st.dev paid builder, credits, MCP, or team features

Free public examples may be inspected when legally available, but the implementation must not require a paid account or paid runtime.

## License Check

Before adding external code or assets:

1. Find the license in the source repository or the individual snippet.
2. Confirm commercial use and attribution requirements when relevant.
3. Record attribution in the project if the license requires it.
4. Prefer existing dependencies when licensing is unclear.
