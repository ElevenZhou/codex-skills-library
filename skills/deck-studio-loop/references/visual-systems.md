# Visual Systems

## Anti-Generic Rules

Avoid:

- Default blue-purple AI gradients unless the brand explicitly requires them.
- Repeating identical cards on every slide.
- Decorative blobs, bokeh orbs, empty abstract backgrounds, and meaningless circuit patterns.
- Text-heavy slides with tiny body copy.
- Using generated images that contain corrupted text.
- Split hero layouts that feel like stock templates when a full-bleed or strong editorial composition is better.

## Build A System

Define these before production:

- **Palette:** 2 neutrals, 1 primary, 1 secondary, 1 accent, line color.
- **Page rhythm:** title placement, footer, section markers, margins.
- **Typography:** title size, subtitle size, body size, table text size.
- **Graphic language:** flows, architecture layers, tables, charts, icons, image treatment.
- **Image policy:** which slides use real/generated visuals and which use editable shapes.

## Style Direction Bank

### Enterprise Trust

Use for government, finance, professional services, audit, legal, compliance.

- Palette: ink, ivory, deep green, copper/gold, restrained teal.
- Layout: calm margins, strong hierarchy, tables and architecture diagrams.
- Mood: credible, controlled, precise.

### Product Operating System

Use for SaaS, developer tools, AI platforms, system demos.

- Palette: graphite, silver, cyan, mint, small amber highlights.
- Layout: interface frames, workflow strips, status panels, product maps.
- Mood: technical, live, operational.

### Premium Consulting

Use for BP, strategy, board, investor or partner decks.

- Palette: ivory, charcoal, deep sea green, muted copper.
- Layout: concise claims, strong tables, chapter dividers, restrained charts.
- Mood: clear, senior, decision-oriented.

### Future Category Creation

Use for innovation, launch, category narrative, roadshow.

- Palette: warm white, deep gray, coral, lake blue, neon green only as accent.
- Layout: large claims, flywheels, market maps, cinematic section breaks.
- Mood: ambitious but grounded.

## Text And Image Choice

- Use generated raster images for mood, cover, product scene, conceptual visual, or hero asset.
- Use editable PowerPoint objects for diagrams that need precise labels.
- Use HTML/SVG-rendered PNG for complex Chinese infographic pages when exact typography matters.
- Never rely on image generation for exact Chinese paragraph text.
