# Automation Workflow

Use Codex automations to run memory maintenance on a schedule. The skill defines what to do; the automation defines when to do it.

## Recommended Sources

Use one or more explicit sources:

- A folder of exported ChatGPT/Codex conversations.
- A project `docs/`, `notes/`, `logs/`, or `journal/` folder.
- A daily capture file such as `00 Inbox/Memory Inbox.md`.
- A run-specific Markdown file pasted or generated by another workflow.

Do not assume the automation can access private historical conversations unless the app exposes them or they have been exported to files.

## Suggested Cron Prompt

```text
Use $obsidian-memory to run a memory maintenance pass.

Vault: /absolute/path/to/ObsidianVault
Sources:
- /absolute/path/to/source/folder
- /absolute/path/to/another/source.md
Time window: files modified since the previous run, otherwise the last 24 hours.
Mode: write changes.
Run log: append to 99 System/Memory Runs.md.

Tasks:
1. Extract durable memory, project updates, decisions, lessons, patterns, and open loops.
2. Update existing notes first; create new notes only when needed.
3. Keep uncertainty explicit and avoid copying secrets.
4. Report files changed and top open loops.
```

## Suggested Schedule

- Daily evening: process inbox and recent work notes.
- Weekly review: consolidate open loops, decisions, and project statuses.
- Monthly review: prune stale inferred memories and archive completed projects.

## Idempotency

Each run should avoid duplicating bullets. Before appending a timeline/open-loop item, search the target note for the same date and key phrase. If a run has no new durable items, only append a short line to the run log.
