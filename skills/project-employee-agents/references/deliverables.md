# 管理成果标准

成果不是长文，而是推动决策和执行的证据。每份成果都应包含：目的、适用范围、更新时间、负责人、输入来源、结论、置信度、决策请求、风险、下一步和验收方式。

## 证据等级

- A：可复核的一手数据、用户行为、运行结果或签署文件。
- B：可信的二手来源、访谈记录、历史基线或多方一致观察。
- C：经验判断、类比、待验证假设。

使用 C 级证据时必须配验证动作和截止时间，不得直接当成事实。

## 成果类型

| 成果 | 适用岗位 | 必须回答 |
| --- | --- | --- |
| 项目简报 | CEO、COO、项目经理 | 为什么做、做什么、不做什么、谁负责、何时验收 |
| 市场/客户简报 | 市场、客户、产品 | 谁需要、证据是什么、替代方案、购买/使用阻力 |
| 决策记录 | CEO、COO、项目经理 | 选了什么、为何选、舍弃什么、代价和复查时间 |
| 风险台账 | COO、项目、技术、测试、财务 | 风险、概率、影响、触发器、负责人、应对和截止时间 |
| 方案/PRD | 产品、策划、技术、设计 | 目标、场景、范围、验收、指标、依赖和非目标 |
| 发布/投放计划 | 技术、测试、市场、投放 | 目标、批次、预算、监控、止损、回滚和责任人 |
| 经营复盘 | COO、财务、产品、市场 | 目标与结果、偏差、原因、单位经济、继续/停止建议 |
| 结项报告 | 项目、COO、财务、客户 | 交付、合同、成本、收益、未决风险、资产和经验 |

## 评分门

每项成果用 0-2 分评分：事实可追溯、目标清晰、责任明确、风险可见、下一步可执行、验收可检查。低于 9/12 分不得作为下一阶段的唯一依据。
