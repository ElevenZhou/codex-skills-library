# 运维模板

## 1. 巡检报告

```markdown
**结论**：正常 / 有 N 项异常（最严重的一项）

| 层 | 对象 | 状态 | 证据 |
| --- | --- | --- | --- |
| 主机 | CPU / 内存 / 磁盘 / 负载 | | |
| 进程 / 容器 | | | |
| 网关 / 反代 | | | |
| 证书 | 到期日 | | |
| 公开入口 | | | |
| 真实业务请求 | 请求体、耗时、结果 | | |
| 账务 / 状态 | | | |

**异常排序**：……
**未知**：……（为什么查不到）
**下一步**：……（只读或待授权）
```

## 2. 故障报告

```markdown
**结论**：问题在 <层>；影响 <谁 / 多少>；当前 已恢复 / 未恢复

- 时间线：发现 → 取证 → 定位 → 处置 → 恢复
- 影响：用户 / 请求数 / 是否有扣费失败
- 证据：日志片段摘要、指标、变更记录（不贴凭证）
- 根因：（confirmed / inferred）
- 处置：做了什么，授权原话
- 验证：真实请求结果
- 计费影响：交老九逐笔核对的请求范围
- 预防：最小改进动作
```

## 3. 变更单

```markdown
**变更**：<一句话>
- 授权：（本人原话、时间）
- 范围：主机 / 服务 / 配置项
- 盘点：变更前状态（证据）
- 备份：路径
- canary：哪个节点 / 多少流量，观察多久，成功线
- 验证：本地 + 公开 + 真实业务请求
- 放量：步骤
- 回滚：触发条件和步骤
- 结果：成功 / 已回滚
- 回写：更新了哪些 README / runbook
```

## 4. 默认安全动作（无需授权）

只读命令：查看进程、容器、日志、指标、配置（不显示凭证）、网络连通、证书到期、版本。

## 5. 必须授权的动作

重启、停止、部署、回滚、改配置、改价格 / 计费、扩缩容、改防火墙 / 端口、轮换或读取凭证、删除数据 / 日志 / 镜像、开详细日志。
