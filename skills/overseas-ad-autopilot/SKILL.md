# Overseas Ad Autopilot

Skill version: `2026.07.24`

Use this skill when the user wants to plan, structure, review, or operate an overseas advertising autopilot workflow.

## Workflow

1. Confirm the objective, target audience, input sources, constraints, and deliverables using `notes/overseas-ad-autopilot-input-checklist.txt`.
2. Fill or update the work contract in `notes/overseas-ad-autopilot-contract.txt`.
3. Assign work lanes from `agents/overseas-ad-autopilot-roles.txt` when the task needs multiple specialist perspectives.
4. Track verification in `qa/overseas-ad-autopilot-qa-ledger.txt` before final handoff.

## Output Standard

- Keep assumptions explicit.
- Separate campaign facts from recommendations.
- Include source paths or links for any supplied material.
- Finish with deliverable paths, validation performed, and remaining risks.
