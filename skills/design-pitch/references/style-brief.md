# 风格说明与提示词（多色彩 · 高饱和 · 梦幻 · 科技动感）

## 1. 可直接复制的调用提示词

**一句话版**（日常用）：

```
比稿：给【页面/看板名】出 3 个方向，用真实数据。我要高水准的，多色彩、高饱和、梦幻感、科技动感，带一点动态效果，信息还要清楚好读。浏览器里验收好，给我对照台和推荐。
```

**完整版**（重要项目用，括号里换成你的内容）：

```
用「设计比稿」技能，为【对象：例如 派发看板 / 官网首页 / 数据大屏】做比稿。

目标与用户：【谁在用，用来做什么，首屏 10 秒内必须看到什么】
数据：用【真实数据来源/文件】导出快照，不要编造；需要"正在发生"的效果就用真实记录做演示回放并标注。
必须有的内容：【逐条列出模块】
必须有的状态：加载、空、断线/出错、减少动态、选中、键盘焦点、筛选为空、操作反馈。

审美：一定要高水准。我喜欢多色彩、高饱和、梦幻感、科技动感，再带一点动态效果。
- 氛围放在框架里（背景、边框、状态、身份色），数据保持安静（文字、数字、终端清楚可读）。
- 动效只表达状态变化，不做无意义的循环；切走标签页暂停，系统"减少动态"时静止。
- 不要千篇一律的紫蓝渐变 + 玻璃卡片，不要默认字体。

方向：3 个互斥方向（页面骨架、字体、底色、材质、动效、标志时刻至少 4 项不同，至少一个浅色方向）。
【可选：指定方向，例如 极光星云 / 霓虹赛博网格 / 全息棱镜】
视口：桌面 1440×900 + 手机 390×844，手机必须重新编排。

流程：先锁契约 → 并行做三版 → 真实浏览器逐个验收（截图、状态页、交互、无报错、无溢出）→ 每版按截图问题改一轮 → 对照台 + 评分 + 按场景推荐。
交付：对照台地址（本机 + 局域网）、三个全尺寸页面、契约、评分表；写明没验证到的地方。
充分利用相关技能（frontend-design-lab、advanced-frontend-design、dataviz、playwright）。
```

## 2. 审美要点（落地时怎么理解"多色彩高饱和梦幻科技动感"）

| 词 | 落到设计上 | 反例 |
|---|---|---|
| 多色彩 | 一套**有秩序**的多色系统：身份色（每类对象一种高饱和色相）+ 状态色（另一组）+ 底色，三者互不冲突 | 彩虹乱用、每个按钮一个颜色 |
| 高饱和 | 饱和色用在**面积小但关键**的地方：描边、光晕、色环、图形、进度；大面积用深底或珍珠底托住 | 大面积饱和色铺满导致文字看不清 |
| 梦幻感 | 光、雾、柔光晕、极光、虹彩、景深；节奏慢而连续 | 堆玻璃拟态、到处模糊 |
| 科技动感 | 精确的等宽数字、计数跳动、扫描/流光、网格、实时流入的事件 | 假 HUD、没有功能的装饰数字 |
| 动态效果 | 每个动效对应一个状态变化：新事件流入、计数增加、完成爆光、选中过渡；背景氛围单层低功耗 | 无限循环抖动、所有元素同时动 |
| 高水准 | 有标志时刻（一个和产品本身相关、让人记住的设计点），字体有性格，所有状态都做全，并且在浏览器里亲眼验过 | 只有一张好看的截图 |

## 3. 方向库（每次从中挑 3 个，或按需求新造；保持互斥）

| 方向 | 论点 | 骨架 | 字体 | 底色 | 材质 | 动效 | 标志时刻（可按产品改写） | 风险 |
|---|---|---|---|---|---|---|---|---|
| 极光星云 | 夜空观测台，对象是轨道上发光的星团 | 中央星图 + 侧栏目录 + 侧滑详情 | 宽体几何展示字 + 细中文 | 深靛紫 | 光、雾、星云 | 滑行、呼吸 | 每个事件给星团添一颗星，完成时超新星绽放 | 密度低、辉光伤可读性 |
| 霓虹赛博网格 | 合成波控制台，每个对象是一条实时音序轨道 | 频道栏 + 横向轨道 + 底部终端坞 | 窄体科技字 + 大量等宽 | 近黑 | 像素、CRT 荧光、LED | 卡点、硬切 | 地平线网格速度随活动量脉动 | 长时间压力大 |
| 全息棱镜 | 珍珠实验台，每个对象是一束被棱镜分出的光 | 顶部时间光谱河 + 焦点舞台 + 丝带列表 | 有表情的展示字 + 巨型数字 | **浅色**珍珠暖白 | 全息箔、棱镜 | 弹性、随指针流光 | 焦点卡随鼠标倾斜泛出全息光 | 浅底彩色对比度 |
| 液态镭射 | 流体金属与镭射色在缓慢流动 | 大画布 + 浮动信息岛 | 圆润几何 + 等宽数字 | 石墨灰 | 液态金属、镭射膜 | 黏滞流动、形变 | 数据变化时液面产生涟漪 | 性能、可读性 |
| 深海荧光 | 深海生物发光，对象是浮游的荧光体 | 纵深分层 + 侧边测深尺 | 窄高字 + 柔中文 | 深蓝绿 | 水、气泡、生物荧光 | 漂浮、脉动 | 活跃度越高，荧光体越亮、越往上浮 | 偏暗、层次难读 |
| 梦境纸雕 | 多层彩色纸雕叠出的景深 | 分层卡片舞台 + 时间轴 | 圆体展示字 | **浅色**奶油 | 彩纸、投影 | 视差、翻页 | 完成时一层纸雕立起来 | 信息密度低 |
| 等离子仪表 | 高能实验室仪表盘 | 环形仪表阵列 + 读数墙 | 工程字 + 等宽 | 深炭黑 | 金属刻度、等离子光 | 指针惯性、充能 | 每个指标是一个会"充能"的环 | 假仪表风险 |

选择原则：至少 1 个深色、1 个浅色或中间调；至少 1 个"信息密度优先"、1 个"氛围优先"；不要选两个只是配色不同的方向。

## 4. 身份色建议（高饱和、在深浅底上都可调）

电光青、珊瑚橙、霓虹紫、品红、酸性绿、琥珀金。文字使用同色相的深色版本（浅底）或高亮版本（深底），保证 4.5:1；纯饱和色只用于填充、描边和光效。
