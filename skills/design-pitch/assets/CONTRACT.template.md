# 【对象】比稿 · 共享契约（所有方向必须一致）

## 产品
- **用户**：【谁】
- **要完成的事**：【一两句】
- **首屏 10 秒内必须看到**：【列出】
- **气质要求（用户原话）**：【例如：多色彩、高饱和、梦幻感、科技动感，带一点动态效果，高水准】。规则：【工具/看板写：氛围在框架里，数据保持安静——正文、数字必须清楚可读】。

## 固定数据与行为（来自 `shared/`，不可改）
- `shared/data.js`：【N 条】真实记录快照（`window.APP_SNAPSHOT`），由【导出脚本路径】生成。
- `shared/core.js`：全部行为，API 见文件头注释。【如有：X 条真实记录以演示回放方式循环"进行中"（`demo === true`），必须标注「演示回放」】。
- 方向目录只写自己的 `index.html`、`styles.css`、`app.js`（可选 `bg.js`）。加载顺序：`../shared/data.js` → `../shared/core.js` → 自己的脚本。

## 每个方向都必须有的内容
1. 【页头：名称、状态、关键指标】
2. 【主区：……】
3. 【列表/历史：字段、筛选、搜索（`/` 聚焦）、筛选为空提示 + 清除按钮】
4. 【详情：字段、操作按钮、关闭（按钮 + Esc）】
5. 【洞察/图表：纯 SVG/CSS，不用图表库】
6. 提示 toast（`aria-live="polite"`）。

## 必须实现的状态
`?state=loading` 骨架屏 · `?state=empty` 空状态（给出下一步引导）· `?state=offline` 断线横幅 + 重试 · `?state=error` 读取失败 · `?motion=reduced` 与系统"减少动态"：背景静止、无循环动画 · 选中态 · 键盘焦点可见。

## 身份色（色相家族固定，数值各方向自调）
【类别 1 = 色相 · 类别 2 = 色相 …】。状态色另成一组，不与身份色混淆。

## 技术约束
- 纯静态：HTML + CSS + 原生 JS，无框架、无 npm、无外部 JS 库。字体可用 Google Fonts 并写回退。不用位图，背景自绘。
- 用户文字一律转义后插入。
- 每秒更新只改变化的文本节点，不整页重建；列表只在 init/filter/finish 重建；不打断输入框焦点、不让动画每秒重启。
- 自绘动画用 rAF，`document.hidden` 暂停，reduced 静止；只动 transform/opacity/canvas。
- 正文对比度 ≥ 4.5:1（以实际背景计）；按钮是 `<button>`；焦点环清楚。

## 视口
桌面 1440 × 900，手机 390 × 844。手机必须重新编排；详情在手机上是全屏层。

## 验收
无控制台报错、无横向溢出、所有内容块与状态可见、筛选/搜索/选中/关闭/操作/键盘可用。
