技能名称：动量爆发筛选（stockbee-momentum-burst-screener）
分类：选股与筛选器
能做什么：按Stockbee动量爆发法扫描美股短期突破候选并评分分级
你提供什么：FMP 数据源账号，或直接给股票代码列表 / 含日线 OHLCV 的 JSON 文件
你会得到什么：JSON 与 Markdown 报告，含触发类型（4%突破/美元突破/区间扩张）、当日涨幅、量比、收盘位置、前期整理宽度、入场与止损参考、风险百分比，以及评分、评级、状态与淘汰原因
触发说法示例：「帮我找最近出现4%放量突破、可能走短线行情的股票」
依赖条件：默认可离线，部分功能需联网；需本机运行技能自带脚本
备注：提供 OHLCV JSON 时可完全离线运行；结果仅作候选生成，非自动下单
