技能名称：形态熟练度训练（stockbee-setup-fluency-trainer）
分类：交易心理与复盘
能做什么：把动量爆发筛选结果建成形态模型簿并跟踪3/5日结果
你提供什么：上游动量爆发筛选器的 JSON 报告（或兼容的候选 JSON）；可选 FMP 数据源账号 或离线 OHLCV JSON 用于更新结果
你会得到什么：JSONL 模型簿（state/stockbee/model_book.jsonl）及摄入/更新/汇总的 JSON 与 Markdown：3日/5日收益、MFE/MAE、止损命中、结果标签、分组统计
触发说法示例：「把这些动量爆发候选建成模型簿，看看哪种形态更容易走强」
依赖条件：默认可离线，部分功能需联网；需本机运行技能自带脚本
备注：需 Python 3.10+；分组统计当作证据提示，不自动改交易规则
