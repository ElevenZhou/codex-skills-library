# 量化交易 AI 技能库

本包是**给交易者与量化研究者用的 AI 技能合集**：把各行业从业者写好的成熟做法收集起来、翻成中文、按岗位工作流分好类，做成一个可以搜索的离线目录。

共 **131 个技能**，分 **11 个分类**。

## 三步上手

1. 打开 `01_目录/量化交易AI技能库-离线目录.html`（双击即可，不用联网），搜索你要解决的问题，比如"筛选""回测""技术分析"。表格里每个技能都标了<strong>它做什么、你提供什么、你会得到什么</strong>，点一行还能展开触发说法示例与依赖条件；
2. 看 `02_教程/` 里的图文教程，选一个你手头有的 AI 工具，把技能装上；
3. 回到 `03_Skills/按中文索引/`，按目录名找到那个技能的文件夹，把它直接拖进 AI 对话框发出去，说一句「帮我把这个技能装上，装好告诉我」——AI 自己会装，你不用知道技能目录在哪。装完重启一次工具。

## 为什么要用技能

不装技能，AI 每次都从零开始答；装了技能，它按固定的行家流程干活——该问什么、该查什么、按什么格式输出，都写死在技能里。同一个问题，输出质量差一个档次。

## 内容边界

- 本包**不包含**任何账号、登录信息、程序调用凭据、额度或网络配置；
- 技能正文取自原作者原文，中文名称与说明为本包整理成果；
- 本技能库为交易研究与分析辅助工具，所有输出不构成任何投资建议、买卖依据或收益承诺；市场有风险，交易决策须由您独立判断并自行承担相应后果。历史回测结果不代表未来表现，涉及具体数据请以交易所与持牌机构披露的信息为准。
