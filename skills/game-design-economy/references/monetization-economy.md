# 变现经济：抽卡、激励广告、内购价格阶梯

数值均为**参考值，按品类校准**。涉及概率公示、未成年人消费限制、平台政策时见 `game-dev-workflow/references/monetization-compliance.md`（检查清单，不是法律意见）。

## 1. 抽卡 / 掉落

- 核心设计量：基础概率、软保底起点与步长、硬保底、50/50 或 UP 机制、是否继承保底计数。
- 用 `drop_rate_calc.py` 回答：
  - 平均几抽、中位几抽、P90/P99 几抽（P99 决定投诉量）。
  - 最坏情况花费（硬保底 × 2 若有 50/50）。
  - 凑 K 份的期望与尾部（`copies`）。
- 规则：
  1. 公示的概率必须等于实际程序概率；保底机制要写在规则页。
  2. 保底计数是否跨池继承，写进设计文档和埋点（`pity_count` 属性）。
  3. 重复获得要有补偿（碎片/转化），否则"抽到重复"是流失点。
  4. 付费抽卡预算：用 `最坏情况抽数 × 单抽价格` 估算上限，评估对不同玩家分层是否合理。
- 免费路径：免费抽数应足以让玩家在 D3–D7 体验一次保底进度的 30–50%（参考值），让他理解机制。

## 2. 激励视频经济（IAA）

- 点位：复活、奖励翻倍、免费道具、体力补充、解锁试用。位置在失败结算、胜利结算、商店。
- 奖励定价：奖励价值 ≈ 玩家 1–3 分钟自然产出；翻倍类 ≤ 2x；强力道具类要限制每日次数。
- 频率控制：每日上限（常见 5–10 次/日）、冷却时间；用远程配置可调。
- 预估收益：`ARPDAU_ad ≈ 每 DAU 广告展示数 × eCPM / 1000`。例：每 DAU 8 次展示、eCPM $10 → 约 $0.08。eCPM 因地区、渠道、时间波动大，用软启动实测。
- 对经济的影响：`economy_sim.py` 里 `ads_per_day` × `ad_reward_amount` 就是广告注入的货币量；检查 `Income by source` 里 rewarded_ad 占比，超过 40% 通常说明自然产出偏低，玩家被迫看广告，容易产生反感。
- 插屏：放在自然停顿点，新手期不出，冷却 ≥ 60–90 秒，并提供去广告 IAP。

## 3. 内购价格阶梯（IAP）

- 档位（USD 参考，本地化价格按各商店价格层级映射）：$0.99 / $1.99 / $4.99 / $9.99 / $19.99 / $49.99 / $99.99。
- 价值系数：每档给出的虚拟货币量 / 价格，应随价格增长但增幅递减（给大额购买"折扣"），例如：
  | 档位 | 价格 | 硬币 | 每 $ 硬币 |
  |---|---|---|---|
  | S | $0.99 | 100 | 100 |
  | M | $4.99 | 580 | 116 |
  | L | $9.99 | 1250 | 125 |
  | XL | $49.99 | 7000 | 140 |
- 首充：高性价比（2–5x）一次性礼包，价格 $0.99–$1.99，目标是让玩家完成"第一次付费"。付费转化的关键是第一次。
- 常见品：去广告（$2.99–$5.99）、月卡（$4.99 级，每日领取，吸引日留存）、通行证（赛季 $4.99–$9.99）、限时礼包（基于行为触发，例如卡关时）。
- 过滤规则：付费点不要出现在新手期前几分钟；促销触发要有冷却。
- 检查：免费玩家能否在合理时间内（如 2 倍时长）达到同样进度（若是"付费加速"型），否则就是"付费墙"，会伤害留存和评价。

## 4. 综合收入估算（占位公式）

```
日收入 = DAU × (ARPDAU_ad + 付费率 × ARPPU_日化)
LTV(Dn) ≈ Σ_{d=0..n} 留存(d) × ARPDAU
```
`economy_sim.py` 给出活跃曲线（`active%`），乘以 ARPDAU 即可得到粗略 LTV 曲线；G5 用实测替换。
