# 成长曲线与难度曲线

以下区间均为**参考值，按品类校准**；用 `scripts/` 里的工具验证，不要照抄。

## 成长曲线（升级成本）

- 指数阶梯：`cost(n) = base * growth^n`。休闲/放置常见 growth 在 1.10–1.35；越大后期越陡。
- 产出也要涨：`income(n) = base_income * (1 + k*n)`（线性）或 `* m^n`（指数）。关键看**两者比值**：
  - 买下一级所需"局数" = `cost(n) / income_per_session(n)`。
  - 目标：新手期 1–2 局一级；中期 3–6 局；后期不超过 10–15 局，否则要靠广告/付费/新内容分流。
- 常见公式：
  | 名称 | 公式 | 特点 |
  |---|---|---|
  | 线性 | `a + b*n` | 前期平、后期无压力，缺紧张感 |
  | 指数 | `a * g^n` | 爆发感强，后期必须配新 sink |
  | 多项式 | `a * n^p` (p=1.5–2.5) | 较平滑，常用于经验表 |
  | 分段 | 每章换一条曲线 | 方便调章节节奏 |
- 软上限：等级上限 + 转生/重置（元成长）比无限指数更稳定。

## 难度曲线

- **锯齿（sawtooth）**：每 4–6 关一个"小峰"，峰后一到两关缓冲（relief）。最常用于关卡制休闲游戏。
- **阶梯（stairs）**：每段稳定后再抬一档，适合有"章节"的结构。
- **斜坡（ramp）**：只用于短流程或教学期。
- **波浪（wave）**：平滑起伏，适合无尽模式的难度调度。

要点：
1. 前 3 关强制简单（教学），首次失败要晚一点出现（常见第 4–8 关）。
2. Boss/卡点关目标胜率 30–50%；普通关 60–80%；缓冲关 80–90%（参考值，休闲类）。
3. 相邻关卡难度跳变 >2.5 分（0–10 刻度）需要有意图（Boss），否则会出现"断崖"流失。
4. 连败保护：同一关连续失败 N 次（常见 3–5）后给提示、降低难度、或送一次免费道具。
5. 难度分是**设计目标**，要用埋点的"每关胜率/平均尝试次数/流失点"回填；流失集中在某一关就是断崖点。

## 目标胜率到期望尝试

期望尝试次数 = `1 / 胜率`（独立重复近似）。胜率 40% → 2.5 次。若一关期望尝试 >4 次，应配置辅助（提示、跳关、广告复活）。
