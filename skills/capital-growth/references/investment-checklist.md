# 投资检查表

## 1. 投资目标与约束

| 项 | 内容 |
| --- | --- |
| 目标 | 保值 / 稳定增值 / 高风险高回报 / 对冲 / 学习（写清楚） |
| 可投资金上限 | 亏完也不影响生活或业务的金额 |
| 时间范围 | 短期（< 1 年）/ 中期（1–3 年）/ 长期（> 3 年） |
| 风险承受 | 最多能亏多少比例 |
| 流动性要求 | 什么时候可能要变现 |

## 2. 标的评估

| 项 | 内容 |
| --- | --- |
| 标的 | 名称、代码、类别（股票 / 基金 / 债 / 加密 / 定存 / 保险） |
| 买入逻辑 | 基于什么证据（财报、行业、技术面、宏观），不用"感觉好"或"别人推荐" |
| 估值或合理区间 | 依据 |
| 已知风险 | 政策、流动性、标的破产、技术失效、黑天鹅 |
| 最坏情况 | 归零 / 腰斩 / 长期套牢 / 退市 |

## 3. 仓位与止损

| 项 | 内容 |
| --- | --- |
| 仓位 | 占可投资金的比例，不超 1.0 |
| 分批规则 | 一次买完，还是分 N 批、按什么条件加仓 |
| 止盈线 | 涨到多少或达到什么条件卖出 |
| 止损线 | 跌到多少或什么条件无条件止损（必须有） |
| 复投规则 | 卖出后什么时候、什么条件再买 |

任何标的没有止损线，结论只能是"不买"或"先定止损线"。

```markdown
- 实际走势 vs 预期：
- 有效的判断：
- 失效的判断：
- 调整：持有 / 加仓 / 减仓 / 清仓 / 修改止盈止损
- 经验：（可复用的，写进投资方法库）
```

## 5. 华强判断输出

结论只能是：**买（仓位 + 止损）** / **卖（理由）** / **持有（复盘节点）** / **不买（原因）**。
