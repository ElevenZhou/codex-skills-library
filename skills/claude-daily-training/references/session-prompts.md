# Session Prompts

Use these prompts for Claude.ai daily training. Fill blanks before sending.
All prompts below are written in English so they can be reused across accounts.

## Engineering

```text
Act as a senior software engineer. I want a practical engineering training session, not abstract advice.

Task:
Help me analyze this software/system problem and produce one useful artifact today. This session should continue from yesterday's work, not restart it.

Context:
- Account group:
- Yesterday's artifact or note:
- System/domain:
- Current issue or goal:
- Constraints:
- What I already tried:

Output format:
1. Clarifying assumptions
2. Likely root causes or design tradeoffs
3. Step-by-step implementation or debugging plan
4. Test/checklist
5. One concise next action

After your answer, ask me one sharp follow-up question that would improve the solution.
```

## Short Drama Writing

```text
Act as a short drama screenwriter and story editor. I want a scene that is emotionally clear, fast, and playable.

Task:
Develop one short-drama scene from this seed. Make it a continuation of yesterday's material, so the emotional arc feels connected.

Context:
- Account group:
- Yesterday's scene or hook:
- Genre:
- Main character:
- Opponent/pressure:
- Secret or misunderstanding:
- Platform/audience:
- Desired emotion:

Output format:
1. One-sentence hook
2. Character wants and conflict
3. 8-beat scene outline
4. Dialogue draft, 400-700 Chinese characters
5. Stronger cliffhanger ending

After your answer, ask me one question about stakes or character motivation.
```

## Video Prompt Writing

```text
Act as a video generation prompt writer and creative director. I want prompts that a video model can actually use.

Task:
Turn this concept into production-ready video prompts. Preserve continuity from yesterday's direction when possible.

Context:
- Account group:
- Yesterday's visual direction or prompt:
- Product/story/object:
- Visual style:
- Camera movement:
- Duration:
- Aspect ratio:
- Must include:
- Must avoid:

Output format:
1. Main video prompt
2. Negative prompt
3. Three alternative style prompts
4. Shot-by-shot version
5. Quality checklist for judging the generated video

After your answer, ask me one question that would make the visual direction more specific.
```

## Universal Prompt

Use this when the track is unclear.

```text
Act as a focused expert collaborator. Today we are doing a real practice session that must produce one reusable artifact.

Track:

Seed:

Account group:

Yesterday's carryover:

Requirements:
- Be specific and production-minded.
- Avoid generic motivational advice.
- Ask one useful follow-up question at the end.
- Produce something I can save, revise, or use tomorrow.

Output:
1. Assumptions
2. Best first version
3. Weaknesses or risks
4. Improved version
5. One next action
```

## Follow-Ups

```text
Make this more concrete and more useful. Point out what is still generic, then rewrite the answer into a stronger version.
```
