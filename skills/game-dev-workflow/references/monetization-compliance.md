# 变现与合规检查清单

**这是检查清单，不是法律意见。** 政策随时间变化（尤其版号、未成年人、隐私、各应用商店政策），每次上线前以官方最新文本为准；涉及主体资质、版号、跨境数据、内购税务时请咨询律师或平台。检查结果记录日期和来源链接。

## 1. 变现模式选择

| 模式 | 适合 | 关键指标 | 风险 |
|---|---|---|---|
| IAA（广告变现） | 超休闲、休闲、H5/小游戏 | 每 DAU 展示数、eCPM、ARPDAU | 广告过多毁留存；平台审核对误导广告敏感 |
| IAP（内购） | 中度、放置、收集 | 付费转化率、ARPPU、首充率 | 数值被质疑、未成年人消费限制、退款 |
| 混合 | 多数休闲 | 广告占比 vs IAP 占比 | 两边体验互相伤害；需要"去广告"包 |
| 买断 / 订阅 | 精品单机 | 转化率、退款率 | 获客成本高 |

规则：
- **激励视频优先于插屏**。激励广告玩家主动看，对留存损伤小；插屏放在自然停顿点（关卡结算后），且新手期（前 N 分钟或前 N 关）不出。
- 广告与付费都要有**远程开关**（上线后能关）。
- 付费数值（价格档位）见 `game-design-economy` 的 IAP 价格阶梯。

## 2. 广告 SDK 检查清单

- [ ] 选聚合（mediation）还是单一网络；记录各网络版本
- [ ] 测试 ID / 测试模式在发布前已移除（用真实广告位 ID）
- [ ] 激励视频：未完整观看不发奖；断网/加载失败有提示且不扣资源
- [ ] 广告加载失败降级（不卡主流程）
- [ ] 插屏频率上限（冷却时间 + 每会话上限），新手期不出
- [ ] Banner/原生广告不遮挡关键按钮，不诱导误点（违反政策会被封）
- [ ] 儿童向内容：使用面向儿童的广告设置（COPPA/Families 政策）
- [ ] 广告 SDK 的隐私清单（采集字段）已体现在隐私政策与商店数据安全表
- [ ] 包体：每个网络适配器的体积已计入预算（`apk_budget_check.py`）
- [ ] ANR/崩溃：SDK 初始化放在后台线程/首帧之后

## 3. IAP 检查清单

- [ ] 商品 ID 与价格档位定稿；跨平台 ID 命名统一
- [ ] 购买流程：成功回调 → 发放 → 持久化 → 确认消耗，崩溃恢复（未确认订单重发）
- [ ] 恢复购买（iOS 必须提供）
- [ ] 本地发放仅用于单机；有排行榜/联网时要服务端校验收据
- [ ] 沙盒/测试账号完整走过一遍
- [ ] 价格、概率（抽卡）展示符合各平台与地区规定
- [ ] 退款/客服流程

## 4. 中国大陆（上线前检查，需确认最新规定）

- [ ] **版号**：内购/收费的网络游戏通常需要出版审批（版号）；纯广告变现的休闲游戏、小游戏的路径与要求不同，必须向平台或律师确认所属类别
- [ ] **主体资质**：运营主体（营业执照经营范围）、ICP 备案（网站/H5）、软著
- [ ] **平台上架**：各安卓渠道与小游戏平台的接入规范和审核资料（版号或替代材料、软著、实名接入）
- [ ] **未成年人保护**：实名认证与防沉迷接入、充值限制、时段限制，按监管要求配置
- [ ] **隐私**：隐私政策首启弹窗、同意前不初始化 SDK 采集、个人信息最小化、第三方 SDK 清单披露
- [ ] **概率公示**：抽卡/盲盒类公示各品类概率，保存日志
- [ ] **内容**：文案/美术审核，不含违规内容
- [ ] **数据**：境内用户数据存储与出境要求

## 5. 海外

**GDPR / 隐私（欧盟/英国）**
- [ ] 隐私政策可访问；数据采集目的明确
- [ ] 同意管理（CMP）：广告个性化需先同意；提供拒绝路径
- [ ] 数据主体权利（删除/导出）的渠道
- [ ] 第三方 SDK 作为处理者的披露

**iOS**
- [ ] **ATT**：若跟踪用户（IDFA），需弹出 App Tracking Transparency 请求并写 `NSUserTrackingUsageDescription`
- [ ] 隐私营养标签（App Privacy）与实际采集一致
- [ ] 恢复购买、订阅说明、审核账号

**Google Play**
- [ ] **Data safety 表**与实际一致
- [ ] 目标 API 级别满足当前要求（Play 每年提高要求，上架前核对）
- [ ] 内购使用 Play Billing；政策对广告、儿童（Families）、赌博类模拟（模拟赌场）等有专门要求
- [ ] 新开发者账号的封闭测试要求（个人账号可能需要满足测试人数/天数后才能发布，上线前核对当前规则）
- [ ] AAB 格式、签名（Play App Signing）

**通用**
- [ ] 年龄分级问卷（IARC/各平台）
- [ ] 抽卡/战利品箱：部分地区要求概率披露或有限制
- [ ] 税务与收款主体

## 6. 记录

在 `docs/compliance-log.md` 中记录：检查项、结论、证据（链接/截图）、核对日期、负责人。上线（G6）前该文件应无未决项，或每个未决项都有明确豁免。发布动作本身遵循 `rebuild-build-release` 的 G-PUBLISH 人工门禁。
