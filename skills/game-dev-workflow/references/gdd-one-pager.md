# GDD 一页纸模板

目标：一张纸讲清楚"这是什么游戏、为什么有人玩、怎么赚钱、怎么做出来"。写不满一页说明想得不够，写超过一页说明没取舍。

复制到 `docs/gdd-one-pager.md` 后逐项填写。`<>` 内是填写提示，**不要留空，不知道就写"未知，G2 验证"**。

```markdown
# <游戏名> 一页纸

版本: <日期>  作者: <>  阶段: G1

## 1. 一句话
<一句话：[目标用户] 在 [场景] 下通过 [核心动作] 达成 [目标]，和 [对标] 的区别是 [一点]>

## 2. 目标用户与场景
- 用户画像: <年龄/性别倾向/设备/付费习惯，来自对标用户或调研，不是想象>
- 典型场景: <通勤 3 分钟 / 睡前 10 分钟 / 工作间隙>
- 单局时长: <秒/分>   日均会话: <次>   日均总时长: <分>

## 3. 核心循环 (30 秒循环 / 5 分钟循环 / 每日循环)
- 30 秒: <玩家一次操作 -> 反馈 -> 下一次操作>
- 5 分钟: <一局/一关: 目标 -> 过程 -> 结算>
- 每日: <回来的理由: 体力/任务/签到/连胜>
- 再来一局的理由: <失败差一点 / 奖励随机性 / 进度可见 / 收集欲>

## 4. 操作与输入
- 平台: <Android / iOS / H5 / 小游戏>  方向: <竖屏 / 横屏>
- 输入: <单击 / 滑动 / 拖拽 / 虚拟摇杆>  单手可玩: <是/否>

## 5. 成长与目标
- 短期目标 (本局): <>
- 中期目标 (本周): <>
- 长期目标 (本月以上): <>
- 成长资源: <金币/经验/碎片/卡牌>  主要来源: <>  主要消耗: <>

## 6. 内容量与节奏
- 关卡/内容总量 (首发): <N>   后续每周新增: <N>
- 新手期 (前 3 分钟): <教什么、不教什么>
- 难度曲线类型: <锯齿 / 线性 / 阶梯>  (见 game-design-economy)

## 7. 变现
- 模式: <IAA / IAP / 混合 / 买断>
- 广告点位: <激励视频(复活/翻倍/免费道具)/插屏(关卡间)/Banner> 
- 付费点: <去广告 / 首充 / 月卡 / 通行证 / 皮肤>
- 目标 ARPDAU: <> (参考值，按品类校准)

## 8. 对标与差异
| 对标 | 市场证据 (下载/收入/评分) | 我们照做的 | 我们不同的 (≤3 点) |
|---|---|---|---|

## 9. 美术与音频方向
- 风格关键词: <3 个>  参考图: <路径>  
- 首发美术量级: <角色 N / 场景 N / UI 套数 N>
- 来源: <自绘 / AI 生成(local-image-generator) / 商用素材包(记许可证)>

## 10. 技术
- 引擎: <> 理由: <>  最低设备: <Android 8 / 2GB RAM>
- 包体目标: <MB>  首次加载: <秒>
- 第三方 SDK: <广告 / 统计 / 登录 / 支付>

## 11. 范围与不做清单
- 首发范围 (MVP): <3-7 条>
- 明确不做: <联网对战 / 公会 / 复杂剧情 ...>

## 12. 里程碑与止损
| 阶段 | 目标日期 | 出口指标 | 负责人 |
|---|---|---|---|
| G2 垂直切片 | | 5 人试玩 ≥3 人无提示完成并再玩 | |
| G3 Alpha | | | |
| G5 软启动 | | D1 / D7 / CPI 达标 | |
- 预算: <人天 / 现金>  止损线: <超过 X 或 G2 两轮不过则停>

## 13. 风险与未知
| 风险 | 概率 | 影响 | 验证方式 / 阶段 |
|---|---|---|---|
```

## 填写检查

- 第 3 节"再来一局的理由"必须是具体机制，不能写"好玩"。
- 第 8 节对标没有市场证据的不算对标。
- 第 11 节"明确不做"至少 3 条。
- 第 12 节止损线必须是可计算的条件，不是"看情况"。
