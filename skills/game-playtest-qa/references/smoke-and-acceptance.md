# 冒烟、里程碑验收与回归清单

## S0 冒烟（每次构建，≤3 分钟）

自动部分（Godot）：
```bash
godot --headless --path . --quit-after 3 2>&1 | grep -E "SCRIPT ERROR|Parse Error|nonexistent"
# 有输出 = 失败。nonexistent 是信号连接失败的唯一征兆。
for t in tests_dev/test_*.gd; do godot --headless -s "$t" || echo "FAILED $t"; done
```
手动/真机部分（`rebuild-device-evidence` 截图留证）：
- [ ] 冷启动到主界面无黑屏/白屏
- [ ] 点开始 → 进一局 → 完成/失败 → 结算 → 返回主界面
- [ ] 退出再进，存档仍在
- [ ] 日志无 `FATAL`、无连续 `ERROR`

H5 游戏：用 `playwright` 打开页面，截图首屏，读控制台 error，走一遍开始 → 结算。

## S1 里程碑验收（沿用 M0–M5 的出口，见 `rebuild-dev-milestones`）

| 里程碑 | 验收项 |
|---|---|
| M0 骨架 | headless 冒烟 0 错误；资源样品加载；工程在干净 checkout 上可跑 |

## 核心功能检查表（G3 回归）

存档
- [ ] 新存档、旧版本存档升级（版本号迁移）、损坏存档（降级为新存档并提示，不崩溃）
- [ ] 中途杀进程后恢复到合理状态（不丢大量进度、不重复发奖）

状态与中断
- [ ] 来电/通知栏下拉/切后台 30 秒/锁屏 5 分钟后返回
- [ ] 旋转/分屏（若支持），否则确认锁定方向
- [ ] 弱网/断网/飞行模式下广告与内购的反应

时间与日期
- [ ] 跨零点、手动改系统时间、时区变化的每日奖励处理（防刷）

输入与 UI
- [ ] 多点触控误触、快速连点、同时按两个按钮
- [ ] 异形屏/刘海/小屏（5 英寸）/ 大屏（平板）UI 不被遮挡
- [ ] 字体与文案溢出（最长语言）

商业化
- [ ] 广告奖励只在完整观看后发放；断网时不扣资源
- [ ] 购买后重启仍有效；重复点击不重复发放
- [ ] 概率公示与代码一致（对照配置）

## 回归清单（每次发版前）

- [ ] 上一版本的已关闭 P0/P1 缺陷逐条复测
- [ ] S0 冒烟全绿
- [ ] 存档升级（上一版本存档 → 新版本）
- [ ] 埋点：关键漏斗事件在后台可见，字段完整（`telemetry_lint.py` + 真机抽样）
- [ ] 包体（`apk_budget_check.py`）与上一版本对比，增长 >10% 需说明
- [ ] 性能：同设备同场景 fps/内存不退化（见 `perf-budgets.md`）
- [ ] 远程配置/开关：关闭广告、关闭活动的路径验证
