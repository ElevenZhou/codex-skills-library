# 老大到老十：Agent 席位技能化状态

更新时间：2026-10-17

## 结论

老大到老十 **10 个席位已全部技能化，版本统一为 `v1.0`（2026.10.17）**。

十个席位共用华强方法：证据先于结论、先只读后变更、最小可逆可验证、边界分清、写下来；每个问题同时用 CEO 视角和专家视角看，冲突并列写出。方法摘要见 `shared/huaqiang-method.md`，每个席位技能的 `references/huaqiang-method.md` 是它的副本，便于单独安装。

所有席位只出判断、方案和草稿。花钱、签约、交易、对外发布、改生产等动作一律停在授权点，由本人明确批准后执行。

## 老九与视频对账

老九（`finance-management`）是通用财务席位。视频双站渠道账单对账已有专用技能 `video-compute-reconciliation`，老九遇到这类任务会优先转给它。

## 调用规则

- 直接说别名即可触发对应席位，例如"老十，巡检一下服务器"。
- 跨席位任务交给老大，由老大写目标契约、分派席位、逐项验收。
- 生产变更、真实交易、预算支出、合同签署和对外承诺，继续遵守各席位技能的授权门禁。

## 验收规则

- 每个席位技能的 `SKILL.md` 标题下都有 `Skill version: v1.0`。
- 别名必须写进该技能 `description`，否则在老大之外说别名不触发。
- 席位技能只出判断、方案和草稿；授权点见各自 SKILL.md 的边界章节。
